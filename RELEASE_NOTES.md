## Was ist neu

- **Im Finder zeigen**: Fertig konvertierte Videos haben in der Liste jetzt eine kleine Lupe. Ein Klick öffnet den Finder und markiert die fertige Datei. Wurde sie inzwischen verschoben, öffnet sich der Ordner.
- Universal-Build (Apple Silicon und Intel), signiert und von Apple notarisiert.

## Installation

1. ZIP entpacken
2. `Videoquetsche.app` in den Programme-Ordner ziehen (eine ältere Version einfach ersetzen)

**Voraussetzungen:** ffmpeg (`brew install ffmpeg`), für Links zusätzlich yt-dlp (`brew install yt-dlp`)
